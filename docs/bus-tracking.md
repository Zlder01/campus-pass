# 버스 위치 추적 설정

들어오는 방향 광역버스(M5107, 5100, 1112, 7000, 1560)의 위치를 1~2분마다 저장해서,
도착정보 API에 아직 안 잡히는 먼 버스(고속도로 위 등)의 도착 시간을 추정합니다.
설정하지 않아도 사이트는 기존처럼 동작합니다.

## 1. 공공데이터포털 활용신청
기존 `경기도_버스도착정보 조회` 외에 아래 두 서비스도 활용신청합니다. 인증키는 같은 키를 씁니다.
- 경기도_버스위치정보 조회
- 경기도_버스노선 조회

## 2. Upstash Redis 연결 (무료)
Vercel 프로젝트 → Storage(또는 Marketplace) → Upstash Redis → Free 플랜으로 생성 후 프로젝트에 연결.
`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 환경변수가 자동으로 추가됩니다.

## 3. TRACK_SECRET 추가
Vercel 프로젝트 → Settings → Environment Variables 에 `TRACK_SECRET` (아무 긴 문자열) 추가 후 재배포.

## 4. 자동 호출 등록 (cron-job.org, 무료)
- URL: `https://<도메인>/api/track?key=<TRACK_SECRET>`
- 주기: 2분 (개발계정 호출 한도가 부족하면 아래 표 참고)

## 5. 확인
- `https://<도메인>/api/track?key=<TRACK_SECRET>&debug=1`
  → 노선별로 찾은 노선 ID, 기준 정류장, 구간 소요시간, 추적 중인 버스 확인
- `https://<도메인>/api/bus` 응답의 `estimates` 에 값이 들어오면 화면에 `[위치 기반 추정]` 으로 표시됨

## 호출량
| 항목 | 2분 주기 기준 |
|---|---|
| 위치정보 API | 노선 5개 × 하루 600회(01~05시 제외) ≈ 3,000건/일 |
| 노선 조회 API | 하루 1번 노선 정보 갱신 ≈ 10건/일 |
| Upstash Redis | 폴링 2명령 + 사이트 요청당 1명령 → 무료 한도(월 50만) 안 |

공공데이터 개발계정 한도가 하루 1,000건이면 2분 주기는 초과합니다.
운영계정(활용사례 등록)으로 올리거나, 임시로 주기를 6분으로 늘리세요 (정확도는 떨어짐).

## 노선을 못 찾을 때
`debug=1` 결과나 `/api/track` 응답에 "노선을 찾지 못했습니다" 가 뜨면,
경기버스정보(gbis.go.kr)에서 노선 ID를 확인해 `ROUTE_IDS` 환경변수에 직접 넣으면 됩니다.
